# v1.1.1 - Service disclosures in both variants

Standard and Compact now both offer independently expandable service lists in every category with registered services. Lists start collapsed, while category purposes remain visible. A chevron beside the label points down when closed and up when open.

The native disclosure responds to clicks, Enter, and Space. The arrow is decorative and hidden from assistive technology; the native expanded/collapsed semantics provide the state. Opening or closing details never changes category switches, writes a decision, or enables optional scripts.

## Upgrade

```bash
composer config repositories.consent vcs https://github.com/jakub-lipinski/consent-for-laravel.git
composer require jakub-lipinski/consent-for-laravel:^1.1.1
php artisan view:clear
```

Register the official VCS source once when installing from GitHub. Merge the updated banner component into customized published views: Standard now also wraps complete service lists in `<details>`, and both variants include the chevron in `<summary>`. Deploy the matching CSS. For separately served styles, republish `consent-assets` after preserving local customizations, then cache-bust the URL and restart persistent workers.

No new configuration or translation keys are required. Consent cookies, service fingerprints, retention, runtime APIs, and saved grants/refusals remain compatible. Standard remains the default appearance. See [the interface guide](../interface.md) for integration accessibility checks.
