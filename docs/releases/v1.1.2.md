# v1.1.2 - Reliable focus and consent withdrawal

This patch fixes three browser runtime defects found during integration testing.

- Focusing a large page container, including a `main` with `tabindex="-1"`, no longer dismisses the pending banner or hides its reopening icon. The overlay still yields when it fully covers the focused host-page control.
- Google, Meta, and Clarity event helpers use an independent event queue. An event waiting for SDK loading cannot delay saving a refusal, and its consent check prevents dispatch after withdrawal.
- Preset readiness is independent of custom script completion. A gated module can await a preset helper without blocking itself and the rest of the loader.

Recurring script timeouts also stop automatic reload loops. Each script gets at most one automatic timeout reload in the tab until it completes successfully. A repeat, or unavailable session storage for the retry marker, emits `consent:reload-required` with `automatic: false` and stops activation. Hosts can offer manual recovery. This does not make removing a script sufficient to stop its running code.

## Upgrade

```bash
composer require "jakub-lipinski/consent-for-laravel:^1.1.2"
php artisan view:clear
```

The release uses the existing PHP, Blade, browser, and configuration APIs. No new configuration or translation keys, cookie migration, policy change, or consent reset is required. Unchanged saved grants and refusals retain their expiry.

Inline components automatically use the installed browser sources. If serving published assets, update both `consent.js` and `banner.js`, preserving any application customizations, and invalidate their cached URLs. Rebuild relevant application caches and restart persistent workers. CSS and banner markup are unchanged from 1.1.1.

Event helper promises indicate submission to the browser SDK, not delivery to a vendor account. `whenIdle()` now includes the event and preset queues. Do not await it from inside a gated module, because it includes that module's completion; await a specific event helper there instead.
